2. API TESTING

Base URL:

http://localhost:8080/api

Tested with Thunder Client.

### CREATE POLICY

POST /policies

Body (JSON):

{
  "description": "Comprehensive motorbike insurance",
  "monthlyPremium": 100.00,
  "startDate": "2026-11-05",
  "endDate": "2027-11-04",
  "clientId": 1,
  "vehicleId": 1,
  "productId": 1
}

Note: Monthly premium is assigned by the backend as the product's base premium so 100 will not be passed.

### GET ALL POLICIES

GET /policies

Expected response: 200 OK

### GET POLICY BY NUMBER
--------------------

GET /policies/{policyNumber}

Replace {policyNumber} with the policy number returned when creating a policy.

### GET POLICIES BY CLIENT

GET /clients/1/policies

### GET POLICY STATUS

GET /policies/{policyNumber}/status

### UPDATE POLICY STATUS

PATCH /policies/{policyNumber}/status

Body (JSON):

{
  "status": "ACTIVE"
}

### DELETE POLICY

DELETE /policies/{policyNumber}
